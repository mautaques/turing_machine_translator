# Sobre
Algoritmo construído em python para traduzir máquinas de Turing de Sipser em máquinas de Turing de fita infinita e vice-versa

# Como usar
- Open the terminal with the shortcut Ctrl + Alt + T

- Clone o repositório com o comando:
```
git clone https://github.com/mautaques/turing_machine_translator.git
```

- Navegue até a pasta do repositório clonado e execute o script com o comando:
```
python3 main.py exemple.in
```

- observe que o arquivo de entrada DEVE estar na mesma pasta que o main.py e ter uma extensão .in

- Ao aplicar as transições no simulador web, o estado inicial deve ser definido como "initial_state"
